# Требования к безопасности
    - Защищённые каналы связи. Шифрование TLS, SSL, возможно VPN.
    - Передавать должен минимальный набор данных, необходимых для работы сервисов
    - При передаче данных, данные клиентов должны быть обезличены (идентификаторы или токены клиентов).
    - Доступы к сервисам по принципу наименьших привилегий
    - Логирование действий с системой

# Протоколы аутентификации и авторизации
    - OpenID connect и OAuth 2.0
    - Проверка авторизации
    - Короткоживущие токены и механизм обновления

# Взаимодействие между системами предприятия и внешней платформой
    Пользователь через мобильное приложение инициирует запрос к внешним сервисам через API. После успешной авторизации получает токен. Далее пользователь через backend мобильного приложения взаимодействует с сервисами операторов.
